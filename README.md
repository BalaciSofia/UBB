## Highlights

- **MiniLang** – an interpreter with heap, garbage collection, concurrency and a
  JavaFX GUI (Advanced Programming Methods), also in its own
  [repository](https://github.com/BalaciSofia/MiniLang)
- **Compiler front end** – scanners and finite automata (Formal Languages and
  Compiler Design), continued in [crochet-mini-lang](https://github.com/BalaciSofia/crochet-mini-lang)
- **AI labs** – neural networks (FashionMNIST), evolutionary algorithms and fuzzy
  rule-based systems
